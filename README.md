<h1><a href="https://www.linkedin.com/in/josephkdminton/">Joseph Minton</a>'s Microsoft 365 Enterprise Lab ☁️</h1>

This project simulates an enterprise Microsoft 365 environment focused on identity and access management, security governance, administrative automation, and help desk operations. Using Microsoft 365 Business Premium, the lab covers user lifecycle management, role-based access control, Conditional Access, Intune device management, data loss prevention, and troubleshooting common Microsoft 365 applications.

[Tenant Architecture & Identity](https://github.com/JosephMinton/Microsoft-365-Enterprise/blob/main/Tenant%20Architecture%20%26%20Identity.md) 🏗️ Established a Microsoft 365 Business Premium trial tenant, provisioned users, configured least-privilege RBAC, and integrated Okta SAML 2.0 single sign-on.

[User Lifecycle & Licensing](https://github.com/JosephMinton/Microsoft-365-Enterprise-Simulation/blob/main/User%20Lifecycle%20%26%20Licensing.md) 👤 Managed user onboarding and offboarding, license assignments, group mailboxes, and external contacts while applying appropriate access permissions.

[PowerShell Administrative Automation](https://github.com/JosephMinton/Microsoft-365-Enterprise-Simulation/blob/main/PowerShell%20Administrative%20Automation.md) 📦 Automated Microsoft 365 user provisioning, bulk CSV imports, license assignments, account offboarding, and deleted-account restoration using PowerShell.

[Security Governance](https://github.com/JosephMinton/Microsoft-365-Enterprise/blob/main/Security%20Governance.md) 🔒 Configured security controls across identity, messaging, collaboration, and data protection to strengthen access restrictions and information handling.

  - [Conditional Access](https://github.com/JosephMinton/Microsoft-365-Enterprise/blob/main/Conditional%20Access.md) 🚧 Implemented baseline and role-specific Conditional Access policies to control sign-in requirements for administrators, staff, and guests.

- [Intune Device Compliance & MDM](https://github.com/JosephMinton/Microsoft-365-Enterprise-Simulation/blob/main/Intune%20Device%20Compliance%20%26%20MDM.md) 📱 Enrolled devices using Microsoft Intune and Windows Autopilot, configured device compliance requirements, and enforced workstation restrictions.

- [Purview DLP](https://github.com/JosephMinton/Microsoft-365-Enterprise-Simulation/blob/main/Purview%20Data%20Loss%20Prevention.md) 🔍 Configured and tested a PCI DSS-based DLP policy across Microsoft 365 workloads, verifying sensitive-data detection through Outlook policy tips.

[Helpdesk Scenarios](https://github.com/JosephMinton/Microsoft-365-Enterprise-Simulation/blob/main/Help%20Desk%20Scenarios.md) 🛠️ Troubleshot simulated Microsoft 365 support tickets involving Outlook, Teams, and OneDrive, documenting symptoms, root causes, and resolutions.

  - [Outlook Troubleshooting](https://github.com/JosephMinton/Microsoft-365-Enterprise-Simulation/blob/main/Outlook%20Troubleshooting.md) 📧 Diagnosed Outlook add-in conflicts, search failures, repeated password prompts, and application issues using a least-invasive-first troubleshooting approach.
       
- [Outlook Command Line Switches](https://github.com/JosephMinton/Microsoft-365-Enterprise-Simulation/blob/main/Outlook%20Command%20Line%20Switches.md) 📨 Used Outlook startup switches to troubleshoot application issues, manage views, and reset client settings, documenting results with before-and-after screenshots.
